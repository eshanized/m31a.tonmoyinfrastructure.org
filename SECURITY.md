# Security Policy

## Reporting Security Vulnerabilities

The M31A team takes security seriously. If you discover a security vulnerability in the M31A web portal or the M31A runtime, please report it responsibly.

### Disclosure Process

1. **Do not disclose publicly** through public GitHub issues or discussions.
2. Submit a report through GitHub Security Advisories:
   - [M31A Security Advisories](https://github.com/eshanized/M31A/security/advisories/new)
   - Or contact the maintainers via security@tonmoyinfrastructure.org.
3. Include details to reproduce the issue (proof-of-concept, screenshots, environment details).
4. Maintainers will acknowledge receipt within 48 hours and work with you on a resolution.

Thank you for helping keep M31A and our community secure!
